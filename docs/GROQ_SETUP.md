# Groq Setup

1. Groq Console-la API key create pannu.
2. Key-a chat/GitHub-la paste panna koodathu.
3. Render -> Environment -> `GROQ_API_KEY` value-la add pannu.
4. `GROQ_MODEL` default `openai/gpt-oss-20b`.

Model availability change aagalam; deployment time-la Groq official Supported Models page-la current production model verify pannu.
